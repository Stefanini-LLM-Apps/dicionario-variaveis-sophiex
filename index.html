Dicionário de Dados SophieX

Documentação oficial do dicionário de dados da SophieX Voz. Estes dados estão estruturados e disponíveis para envio através da API Rest. 

                          
                              Respondido por: Sophie
Nome da Variável Tipo Descrição
AnsweredBy String Agente que está respondendo a chamada durante a ligação através da SophieX.
Message String Histórico da conversa entre usuário e Sophie durante a ligação.
lastUserInput String Última informação dita pelo usuário antes do fim da ligação.
latest20Messages Array Strings Últimas vinte mensagens trocadas entre o Usuário e a Sophie antes do fim da ligação.
callId String String de Identificação da ligação em Sophie.
Ticket String String de Identificação do ticket criado em ITSMs não customizados.
GenesysCloudConversationId String Identificação da ligação em Genesys.
StartedAt ISO Date Data e Horário do inicio da ligação em Sophie.
Language String Idioma da ligação.
To String Number configurado dentro da Sophie.
From String Número de origem da ligação.

Informações coletadas durante a ligação podem ser disponibilizadas, seguindo a lei geral de proteção de dados (LGPD).
